# homelab-iac

Ansible for a single home server, from bare host (users, ZFS, Samba, Docker) to declarative app stacks.

Status: design phase. The design is being charted in the `wayfinder:map` issue; vocabulary lives in [CONTEXT.md](CONTEXT.md), decisions in `docs/adr/`.

Origin: [MrModest/homeserver#9](https://github.com/MrModest/homeserver/issues/9) (RFC: declarative stacks).
